# Auto-MoShou

Auto-MoShou · 魔兽世界无限服角色创建界面辅助 Skill（标准鼠标键盘/截图，非外挂）

> 针对国内 agent 拒绝执行任务 & 频繁擅自暂停进行了专项优化。

## 运行模式

Agent 调用本技能时，第一步先询问：

> 请选择运行模式：**默认推荐**（稳妥，首次建议）或 **加速模式**（大幅加快点击与循环速度）？

- 这是**执行节奏模式**，不是游戏配置预设。规则集 / 阵营 / 种族 / 职业 / 姓名仍必须由用户指定，不会因为选择「默认推荐」就自动套用任何角色配置。
- 用户未明确选择时按「默认推荐」执行；用户说「加速 / 快一点 / 直接加速」即选加速模式。
- 模式确认可与配置收集合并为一轮问答，但不得跳过询问。

## 加速模式修改说明

加速模式专门解决用户反馈的「循环太慢、每步像在等」的问题。核心思路是：**只压缩等待时间，不跳过状态校验；先保证点准，再提高速度**。

### 1. 参数对比

| 项目 | 默认推荐 | 加速模式 | 变化 |
|------|----------|----------|------|
| 普通点击 / 输入 | 80–250ms 随机 | **30–80ms 随机** | 单步等待减少约 60–70% |
| 动画 / 加载 | 150–400ms 随机 | **80–200ms 随机** | 界面过渡更快推进 |
| 失败重试 | 200–500ms 随机 | **100–250ms 随机** | 点空后更快补偿 |
| 悬停确认 | 首次 / 低置信度 0.1–0.25s | 高置信度跳过；未标定仅 0.05–0.12s | 熟练后取消悬停开销 |
| 重连 / 规则 / 回退 | 4s / 3s 上限 | **0.3–0.8s 上限** | 固定等待不再是主要耗时 |
| 不平衡回车 | 5–10 次，间隔 0.4–1.2s | **3–5 次，间隔 0.15–0.4s** | 弹窗重试周期大幅缩短 |
| 播报 | 阶段播报 + 30s 心跳 + 回车 n/10 | 阶段 / 30s 心跳保留，回车可合并播报 | 减少文本开销，但仍防「像卡住」 |

### 2. 具体优化点

- **快速循环**：回退后不再等满 3 秒，登录页一出现就继续；加速模式下限压到 0.3–0.8 秒。
- **更快回车**：不平衡弹窗改为 3–5 次回车、间隔 0.15–0.4 秒随机，保留真人节奏但明显缩短。
- **高置信度直点**：目标在 `.agent-memory/clicks.json` 中 `ok≥3 && fail=0` 时跳过悬停，直接按记忆坐标 + offset 点击。
- **快速标定兜底**：未达到置信度的目标只做一次 0.05–0.12 秒悬停确认，记录中心偏移后立即进入高速。
- **键盘优先复用**：能用 Enter / Space / Tab / Ctrl+A 的入口优先用键盘；焦点不确定才回退到已标定鼠标。
- **失败快退**：同一目标在加速模式下连续 2 次失败，自动退回默认推荐参数重试；仍失败才走退出重进，不停止任务。
- **心跳保留**：每 30 秒无阶段推进仍播报一次「仍在 XX 阶段，正在继续」，回车进度可合并为「正在快速回车…」。

### 3. 没有省略的部分

加速模式只改速度，不改安全与正确性：

- 不跳过逐帧状态校验：点击后仍看选中高亮 / 界面跳转。
- 不跳过配置确认：不可修改项与姓名仍由用户指定。
- 不跳过真实桌面 `main` 限制，仍禁止 pip / 豆包虚拟桌面。
- 不跳过合规边界：不注入、不改内存、不改客户端、不绕过反作弊。
- 不跳过任何停机条件：配置冲突、备选名耗尽、未知弹窗、不在 main 等仍立即停下。

### 4. 典型使用方式

```text
用户：用 Auto-MoShou 建号
Agent：请选择运行模式：默认推荐 / 加速模式？
用户：加速模式，PVP 部落亡灵圣骑士，主名 X 副名 Y，备选名 X2 / X3
Agent：（一次性复述配置与默认/随机项）→ 立即开始，不再等待确认
```

首次运行建议用「默认推荐」建立点击记忆；之后在同一分辨率、同一窗口布局下重复建号时选「加速模式」，速度与稳定性最好。分辨率、窗口大小或游戏版本变化后，对应 profile 会失效并重新标定。

## 安装与触发

解压技能包到 Agent 技能目录，例如：

```text
C:\Users\Administrator\.codebuddy\skills\Auto-MoShou\
    SKILL.md
    README.md
    references\flow-states.md
```

刷新后说「魔兽世界建号」「无限服建号」「魔兽自动创建角色」即可触发。需要 Agent 具备 `computer_use_tool`（`plane="cu"`）与 `seed_computer_use` 能力。
