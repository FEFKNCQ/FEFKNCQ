# 角色创建界面识别与异常处理细则

配合 `SKILL.md` 主状态机使用：记录每个界面的识别特征、按钮位置、已知坐标坑和异常处置。本手册只描述**用户可见 UI** 与标准鼠标键盘输入，不涉及进程注入、内存读写、封包拦截、客户端修改、反作弊绕过或检测规避；使用前请确认符合所涉游戏服务条款。

> **不需要虚拟桌面**：该技能明确限定在真实桌面 `main` 上操作，禁止切到 pip 或豆包虚拟桌面；全程只点游戏窗口，不碰其他程序、不点右上角关闭按钮。我先截屏看一下当前桌面和游戏客户端状态。

**启动前强制检查**：先截屏观察当前桌面与游戏客户端状态，确认在真实桌面 `main` 且游戏窗口可见、客户端处于可操作状态后再继续；任何情况下都不切到 pip/豆包虚拟桌面，也不根据旧帧坐标直接点击。客户端没开或不在登录页时先告知用户，不要盲点。

**决策分层**：规则集、阵营、种族、职业、天裔分支（创建后不可修改）与姓名（无限服无改名服务）必须由用户指定；体型、外观细节、HD/SD 模型创建后可改，Agent 直接默认或随机，用户主动指定时才按用户选择。旧版本中的固定配置（部落 / 男性 / 亡灵 / 圣骑士、「慌啥子嘛 / 慢慢来」）已废弃。

**快速路径**：用户第一句话已明确给出规则集、阵营、种族、职业和姓名时，不必逐层列全选项——对照下表校验合法性、复述确认即可；缺项或非法再回退到逐项列全。只说「PVP 已默认，直接点」不算明确指定规则集，仍要确认一句。

## 创建后能否修改（决定谁来选择）

- **必须用户指定（不可修改）**：规则集、阵营（PVP 锁）、种族、职业、天裔分支。
- **必须用户指定（实际锁定）**：姓名——无限服目前没有改名服务，且重名判定看完整名+姓组合，所以要请用户给 1-2 个备选名。
- **Agent 默认/随机（可修改）**：体型（性别）、发型/肤色等外观、HD/SD 模型、幻化开关、天赋专精、副名在姓名板的显示；这些都可在理发店或选项菜单调整，不占用用户决策成本。

## 运行模式（调用时先问，不跳过）

Agent 被调用后先询问：**默认推荐（稳妥）/ 加速模式（大幅加快点击与循环）**。这是执行节奏模式，不是游戏配置预设；规则集 / 阵营 / 种族 / 职业 / 姓名仍必须由用户指定。用户未明确选择按默认推荐；说「加速 / 快一点 / 直接加速」即选加速模式。

| 参数 | 默认推荐 | 加速模式 |
|------|----------|----------|
| 普通点击 / 输入 | 80–250ms 随机 | **30–80ms 随机** |
| 动画 / 加载 | 150–400ms 随机 | **80–200ms 随机** |
| 失败重试 | 200–500ms 随机 | **100–250ms 随机** |
| 悬停确认 | 首次 / 低置信度 0.1–0.25s | 高置信度跳过；未标定仅 0.05–0.12s |
| 重连 / 规则 / 回退 | 4s / 3s 上限，就绪即继续 | **0.3–0.8s 上限**，就绪即继续 |
| 不平衡回车 | 5–10 次，间隔 0.4–1.2s 随机 | **3–5 次，间隔 0.15–0.4s 随机** |
| 播报 | 阶段播报 + 30s 心跳 + 回车 n/10 | 阶段/30s 心跳保留，回车可合并播报 |

加速模式仍保留逐帧状态校验、真实桌面 main、合规边界和全部停机条件；目标未在 `.agent-memory/clicks.json` 达到 `ok≥3 && fail=0` 时先快速标定，连续 2 次失败退回默认推荐参数，不停止任务。

| 阶段 | 界面 | 识别特征 | 动作 | 等待 |
|------|------|----------|------|------|

| 3 | 角色创建界面 | 左右阵营列、底部职业排 | 阵营 → 种族 → 职业 | 看状态，动画时 0.15–0.4 秒随机 |

## 续跑判定（用户可能已手动操作）

| 当前画面 | 处理方式 |
|----------|----------|
| 登录页 | 点「重新连接」；若用户已推进到规则/创建页，直接跳到对应阶段 |
| 规则页 | PVP 等规则**已选中且正确**就跳过，不重复点；不符才改成用户所选 |
| 角色创建页 | 阵营/种族/职业逐项核对：**已选对就跳过**，不符才改，不整页重置 |
| 外观页 | 体型 1/2、HD/SD 已正确就跳过；用户未指定才默认/随机 |
| 命名页 | 已有名字正确就保留；不一致清空后整段填入；失败换备选名 |
| 结果弹窗 / 角色列表 / 创建完成 | 配置一致直接判成功，不重复创建角色；不一致且不可改才停下报告 |
| 无法判断当前阶段 | 停下说明当前画面，不猜、不从头覆盖 |

原则：**以当前帧为准，能识别就续跑；已正确不重复操作，不正确才自动修正到用户配置，全程不重新询问。**

## 角色创建界面定位

- **不要依赖固定序号或固定头像位置**：不同规则集、阵营、分辨率下职业排和种族头像顺序会变。
- **默认服务器参考特征（仅用于快速识别，不作为点击依据）**：男性多在顶部左侧、亡灵多在部落列第二排灰白头像、圣骑士多在底部第七个。必须以当前截屏文字 / 图标 / tooltip 为准，禁止按序号直接点。
- 每次点击前先截屏，按当前帧 **0–1000 归一化比例**读坐标，辨认文字 / 头像 / tooltip，确认选中项后再进入下一步。
- **阵营与种族**：先确认处于用户所选阵营列，再在该列找到用户指定种族头像（部落列找兽人/亡灵/牛头人/巨魔/塑风者天裔；联盟列找人类/矮人/暗夜精灵/侏儒/高阶会天裔）。
- **职业**：在底部职业排按图标文字/提示找到用户所选职业，不以「从左数第几个」为准。
- **置灰 / 不可点击**：种族或职业图标置灰表示当前组合不可选，**不要强行点击**，停下报告具体缺项，请用户调整种族或职业。
- **体型（性别）**：外观页顶部中间的「体型 1 / 体型 2」按钮；用户未指定时 Agent 默认或随机，切换后截屏确认模型变化。
- **HD / SD**：用户未指定时默认或随机；只影响外观与动作精度。
- **其他外观**：默认不动；用户有明确偏好时调整并截屏确认。

## 命名输入规则

- 输入前先确认光标落在对应输入框；主名填主名框、副名填副名框，**两个名字不要填反**。
- 输入后回看一遍，确认与用户给定值逐字一致，再点【完成】。
- 备选名按顺序尝试，每次重试前重新截屏确认仍在命名界面；备选名全部失败才停下报告。

## 已知坐标坑

- **第三次后退按钮偏上点不到**：前两次后退按左下角按钮常规位置点击；第三次后退时，点击位置在按钮可见区域内往下移一点点，避免落在按钮上沿之外。
- 坐标一律以当前截屏帧为准，禁止硬编码像素；窗口大小变化后位置会偏移。

## 等待节奏（速度优化）

- **固定秒数只是上限**：默认推荐重连/规则页 4 秒、回退 3 秒；加速模式上限压到 **0.3–0.8 秒**——界面提前就绪就立刻继续，不等满。
- 普通点击/输入后按界面状态判断：默认推荐 **80–250ms 随机**、动画 **150–400ms 随机**；加速模式 **30–80ms 随机**、动画 **80–200ms 随机**，**不再统一等 1 秒**。
- 同一界面内坐标与文字只识别一次并缓存；界面切换、窗口移动或弹窗出现才重新截屏定位。
- 等待期间不重复点击同一按钮；姓名整段填入，不逐字输入。
- **心跳播报**：完整尝试开始后 30 秒内未进入下一阶段/未提交，就每 30 秒播报一次「仍在 XX 阶段，正在继续」；进入新阶段重置计时。纯通知，不等用户回复。

## 单帧复用与重试上限（提速且不早停）

1. **一帧一动作**：进入界面截一次屏，动作后的截图直接作为下一步的点前截图，不重复截。
2. **状态校验**：点击后立即看选中高亮/界面跳转；无变化默认推荐等 **200–500ms 随机**、加速模式等 **100–250ms 随机**后重截屏重试。
3. **同一动作最多 5 次**；仍失败先尝试备用定位或重新聚焦游戏窗口，再失败就**退出当前界面重进重试**，不停机。每成功推进一次计数清零。

## 鼠标精准点击与自学习（解决点不准）

| 环节 | 首次 / 低置信度（标定模式） | 熟练模式（高置信度） | 失败补偿 |
|------|----------------------------|----------------------|----------|
| 目标定位 | 截屏识别文字/图标外框，按 0–1000 归一化取**中心** | 直接读记忆坐标 + offset | 重新截屏，确认窗口未移动 |
| 悬停确认 | 移到中心等 0.1–0.25 秒，看 hover 高亮 / tooltip | 跳过，直接点 | 再悬停一次确认目标 |
| 点击 | 外框中心，不点边角 | 记忆坐标 + offset | 中心 ±8、±15 归一化单位微调重试 |
| 状态校验 | 看选中高亮 / 界面跳转 | 看选中高亮 / 界面跳转 | 计算「实际命中 − 预期中心」写入记忆 |
| 记忆更新 | 新建 profile | 成功 `ok+1`、失败 `fail+1` | 连续 3 次失败作废该条并重新标定 |

**本地记忆文件**：技能安装目录 `.agent-memory/clicks.json`（运行时创建，不提交 GitHub）。

```json
{
  "profiles": {
    "1920x1080|fullscreen|PVP|char-create": {
      "亡灵头像": {"x": 412, "y": 305, "offsetX": -4, "offsetY": 3, "ok": 12, "fail": 0, "lastInput": "mouse"},
      "圣骑士":   {"x": 508, "y": 842, "offsetX": 0,  "offsetY": 0, "ok": 12, "fail": 0, "lastInput": "mouse"}
    }
  }
}
```

- `ok≥3` 且 `fail=0` 视为熟练，后续跳过悬停直接点；首次运行不要催速度。
- 分辨率 / 窗口尺寸 / 游戏版本变化 → 对应 profile 失效，重新标定。
- **键盘优先**：弹窗回车；按钮已聚焦用 Enter / Space；命名框 Tab / Shift+Tab + Ctrl+A；规则单选可用方向键但必须确认高亮；Esc 退出当前界面。焦点不确定就回退已标定的鼠标中心点击，键盘结果也写入记忆 `lastInput`。

## 卡住处理（退出重进，不按次数/秒数停机）

- **心跳播报**：30 秒内未推进就每 30 秒播报当前阶段；回车循环每次按键后播报「正在模拟回车 n/10…」。都是纯通知，不等回复。
- **一次完整尝试**超过 3 分钟无结果 → 回退重来，不算停止。
- **再次出现「阵营人口不平衡」= 正常重试**：不计数、不询问，按「默认推荐连按回车 5–10 次（间隔 0.4–1.2 秒随机）/ 加速模式 3–5 次（间隔 0.15–0.4 秒随机）→ 确定 → 后退×3 → 等 3 秒（加速 0.3–0.8 秒）」回登录页继续，循环到成功。
- **同一步骤无法越过或界面长时间无变化**：用游戏内「后退 / Esc」退出当前界面，回登录页重新进入，复用配置快照重试；不按 5 次或 120 秒停机。
- 退出也失败时再试「重新连接」或重新聚焦游戏窗口；仍不行才停下报告当前画面，这是最后手段。
- 无全局 15 分钟总时限，也无重试次数上限。未知弹窗、配置冲突、备选名耗尽、不在 `main`：立即停下，不等超时。

## 异常处置

- **发现自己切到了 pip/虚拟桌面，或当前不在真实桌面 `main`**：立即停止所有点击，切回 `main` 并重新截屏确认游戏客户端状态；绝不在虚拟桌面继续操作。
- **界面未按预期跳转**：先截屏重读当前界面，判断停在哪一阶段，再决定下一步；不要盲目继续点。
- **卡在同一界面**：确认按钮是否被弹窗遮挡；有弹窗先处理弹窗。同一动作连续 5 次无变化或备用定位失败时，**用后退/Esc 退出当前界面重进重试**，不立刻停下。
- **误选阵营 / 种族 / 职业 / 规则集**：进入命名界面之前可返回修改；已提交且不可修改时按失败流程后退重来或停下报告。
- **用户选择不在合法选项内**（阵营无该种族、种族无该职业、天裔未解锁）：停下报告具体缺项，请用户重新选择，不要自行换成别的。
- **名称不可用 / 已存在 / 含非法字符 / 过长 / 违反 RP 命名规范**：按用户给的备选名顺序依次尝试，每次重试前重新截屏确认仍在命名界面；备选名全部失败则停下报告，不要自己编名字。
- **出现非“阵营人口不平衡”的其他弹窗**：先截屏识别弹窗文案，能识别确定/取消类按钮再处理；无法判断时停下报告，不要乱点。
- **不要点窗口右上角关闭按钮**；流程中断后从登录界面重新进入即可。

## 重试循环判据

- **阵营人口不平衡**：先像真人一样**连按回车**：默认推荐 5–10 次（间隔 0.4–1.2 秒随机）/ 加速模式 3–5 次（间隔 0.15–0.4 秒随机）；每次按键后播报「正在模拟回车 n/10…」（加速可合并为「正在快速回车…」）。弹窗消失就从当前画面继续，否则点「确定」→ 后退两次 → 第三次下移点击后退 → 默认等 3 秒 / 加速等 0.3–0.8 秒 → 回到步骤 1。每一轮都重新截屏，配置快照与名字队列沿用用户最初的选择。
- **名称不可用**：换下一个备选名重试当前命名步骤；主名和所有备选名都失败才停下报告。
- 每轮回退后截屏确认回到登录页即重跑，配置快照直接复用。**再次弹出「阵营人口不平衡」算正常重试，不是卡住、不计数、不询问**。
- 同一步骤反复无法越过时用「退出重进」继续，不按次数停机；不设重试次数上限，全程尽量零交互。
- 循环直到无弹窗、成功提交，且角色配置与用户确认结果一致。

## 成功判定

- 不再出现“阵营人口不平衡”弹窗，角色进入角色选择列表或角色创建完成界面。
- 逐项核对：规则集、阵营、种族、职业、主名、副名与用户选择一致；体型、HD/SD 若为默认/随机则核对界面已成功应用，用户有指定时须逐项一致。
- 任一项不一致不得报成功。
